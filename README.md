# Learned Beauty

Website for [www.learnedbeauty.com](https://www.learnedbeauty.com), hosted on GitHub Pages (built with Jekyll).

## Editing texts

Use the browser editor at [https://app.pagescms.org](https://app.pagescms.org) (settings in `.pages.yml`).
Editable there: contact details and prices (`_data/settings.yml`) and the Philosophy page (`about/index.md`).
The other pages are HTML files you can edit directly on GitHub.

## Files

- `_layouts/` – shared header, footer and page templates
- `_data/settings.yml` – email, WhatsApp, fee, number of free sessions, languages
- `index.html` – home page
- `about/` – philosophy and founder
- `privatementorship/` – the mentorship, fee and FAQ
- `apply/` – the three questions and how to send them
- `invitation/`, `privatementoring/`, `application/`, `mentorship/`, `contact/` – redirects from old addresses
- `assets/` – stylesheet (`assets/css/style.css`) and images (`assets/images/`)
